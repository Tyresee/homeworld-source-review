# Review copy, not a deployment replacement

This package preserves the account-product module structure and algorithms for inspection. Branding, namespaces, service identifiers and locale settings are neutral aliases. User-facing copy and test-only display strings use concise English or stable DisplayText identifiers. The original display-text catalogue and all operational credentials are omitted. Some display-matching regular expressions are normalized as well.

These changes mean this is not an exact production source archive, complete localization, or an approved deployment candidate. Do not deploy it against a live platform. Refer to relative module names and functions when proposing changes; the implementation agent will map suggestions back to the actual project.

The source is aligned with a committed account-product snapshot. One later orientation regression test is included; it does not constitute a shipped orientation fix. Uncommitted appearance experiments, historical board/demonstration entrypoints and real deployment configuration are excluded. Imported helper modules remain where the real account graph depends on them.

Only fictional identities and disposable local HTTP fixtures appear in the tests. The real platform service is not part of this package. Production authentication, student selection and real spending require external trusted platform contracts.
