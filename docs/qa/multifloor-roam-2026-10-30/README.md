# Multi-floor browser evidence

All images and geometry measurements use fictional local data and the actual application, service, model builders and controls. There is no real platform/account connection. The public shell uses intentionally normalized display placeholders; free-visit labels are English.

- `01-exterior-1024.png`: two actual storeys and reachable controls, 1024×600 child browsing viewport.
- `02-upper-elevator-1440.png`: physically entered the real door and completed the real elevator sequence; 2F is active, the elevator and different upper bedroom are visible, 1440×900.
- `03-upper-tv-weather-1440.png`: clicked the upstairs TV power, then its real remote; Weather is shown and the hover label updates immediately.
- `viewport-proof.json`: observed button rectangles at real child browsing viewport sizes. Labels from the original product run were translated for this public measurement record; positions were not changed. Every sample has all four buttons within the visible window and no page-height overflow.

Crops remove only the unused outer QA browser area. They do not edit rendered content. Additional implementation-owner browser checks covered elevator travel to floor 2, its television power/remote and exit back through the purchased connection. These are browser checks, not a physical-device performance claim.
